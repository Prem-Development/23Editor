## YouTube upload

1. Sign in to YouTube Studio and choose Create → Upload videos.
2. Select the finished screen recording or assembled demo.
3. Paste the title and description above, replacing the GitHub URL.
4. Choose the audience setting according to the video's actual intended audience. Answer upload disclosures accurately.
5. Complete checks and choose visibility that matches the submission requirements.
6. Unlisted allows anyone with the link to watch. Public also allows public discovery. Private needs explicit viewer access.
7. Save or publish, wait for processing, and test the final URL in a signed-out browser.
8. Put the same working YouTube URL in the GitHub README and hackathon submission.
